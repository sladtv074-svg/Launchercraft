# Launchcraft — Projet complet

## Installation

1. Décompresse le ZIP.
2. Envoie le contenu du dossier `Launchcraft-Projet-Complet` dans ton dépôt GitHub.
3. Le fichier `index.html` doit être directement à la racine du dépôt.
4. Conserve les dossiers `css`, `js` et `assets`.

## Structure

```text
index.html
css/
  style.css
  screensize.css
js/
  index.js
assets/
  images/
    grass-block.png
    background.jpg
    launchcraft-title.png
    play.png
    play-hover.png
```

Le bouton Play tente d'afficher `https://eaglercraft.ir/` dans la même page.
Si le site bloque les iframes, une intégration complète nécessitera les fichiers du jeu hébergés localement.
